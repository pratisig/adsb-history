Mode d'emploi

  1. Données de démonstration : au chargement, un jeu de données simulé de 3 jours (28 → 30/10/2026, Afrique de l'Ouest) permet d'essayer l'outil immédiatement. La période proposée s'étend toujours sur toute la couverture des données chargées.
  2. Importer de vraies données : téléchargez une archive globe_history depuis les releases adsb.lol, puis cliquez sur « Importer des données ». L'archive est lue en flux, sans être envoyée nulle part.
  3. Cumuler plusieurs jours : relancez un import en choisissant la destination « Ajouter au jeu de données actif » — les positions et la couverture temporelle s'additionnent (voir §3 bis du README pour les volumes réalistes).
  4. Requêter : choisissez une zone (bouton « Dessiner » ou zone visible), une période, éventuellement un hex/indicatif, puis « Rechercher ».
  5. Explorer : cliquez sur un point d'extrémité sur la carte ou sur une ligne du tableau « Aéronefs » pour voir la trace complète et les statistiques du vol.
  6. Exporter : les boutons « CSV positions » et « CSV aéronefs » téléchargent les résultats filtrés.

Les données sont conservées dans le navigateur (IndexedDB) sur votre appareil. Aucun compte, aucun serveur, aucune clé API.
