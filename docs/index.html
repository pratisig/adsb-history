Où trouver des données réelles ?
  1. Archives mondiales adsb.lol — la source utilisée par Turnstone : github.com/adsblol/globe_history_2025/releases. Une journée ≈ 3 Go (fichiers .tar.aa + .tar.ab, téléchargez les deux). Sélectionnez la zone « zone visible » et 1 point/minute pour ne garder que votre région.
  2. CSV — tout fichier contenant au moins lat et lon : export OpenSky, dump d'un récepteur tar1090/dump1090, relevé personnel…
  3. Cumuler — pour couvrir plusieurs jours, choisissez « Ajouter au jeu de données actif » à chaque import.

—

Une journée mondiale complète pèse ~3 Go compressés : limitez la zone à votre région et gardez 1 point/minute. Pour couvrir plusieurs jours, importez-les successivement avec « Ajouter au jeu de données actif ».

Mode d'emploi

  1. Données de démonstration : au chargement, un jeu de données simulé de 3 jours (28 → 30/10/2026, Afrique de l'Ouest) permet d'essayer l'outil immédiatement. La période proposée s'étend toujours sur toute la couverture des données chargées.
  2. Importer de vraies données : téléchargez une archive globe_history depuis les releases adsb.lol, puis cliquez sur « Importer des données ». L'archive est lue en flux, sans être envoyée nulle part.
  3. Cumuler plusieurs jours : relancez un import en choisissant la destination « Ajouter au jeu de données actif » — les positions et la couverture temporelle s'additionnent (voir §3 bis du README pour les volumes réalistes).
  4. Données réelles : la carte « 5 · Données réelles » lit le relevé automatique du dépôt (trafic réel des 3 dernières heures autour de Dakar, Saint-Louis, Ziguinchor, Paris, Montréal — sans archive ni clé) et l'ouvre toute seule. « Afficher sur la carte » montre les aéronefs, « Explorer l'historique réel » en fait un jeu de données interrogeable. Pour rafraîchir : lien « demander une mise à jour ».
  5. Requêter : choisissez une zone (bouton « Dessiner » ou zone visible), une période, éventuellement un hex/indicatif, puis « Rechercher ».
  6. Explorer : cliquez sur un point d'extrémité sur la carte ou sur une ligne du tableau « Aéronefs » pour voir la trace complète et les statistiques du vol.
  7. Exporter : les boutons « CSV positions » et « CSV aéronefs » téléchargent les résultats filtrés.

Les données sont conservées dans le navigateur (IndexedDB) sur votre appareil. Aucun compte, aucun serveur, aucune clé API.
